# 中国語写真作文 (Chinese Photo Essay) Webアプリ

写真やイラストから中国語の単語・ピンイン・日本語訳を自動抽出し、作文添削や模範文で楽しく学べる日本人向け中国語学習Webアプリケーションです。

---

## 🌟 主な機能

1. **写真・イラストの超高速AI解析 & スプレッドシートキャッシュ ⚡**
   - 初回解析時は画像を800pxに自動最適化し、最新の高速モデル（Gemini 2.5/2.0 Flash）で迅速に抽出
   - 解析結果（単語一覧、例文、初級/中級模範作文）は自身のGoogleスプレッドシート（「中国語写真作文_データベース」）に自動保存
   - **2回目以降はAIを介さずスプレッドシートから瞬時（約0.5秒）に高速読み込み**
   - 別の視点で新しく生成したいときは「🔄 AIで再解析」ボタンでいつでもリフレッシュ可能
2. **中国語作文・AI添削結果のスプレッドシート自動保存 & 何度でも推敲可能 📝**
   - 「AIに添削してもらう」を実行した瞬間に、**入力した作文とAI添削結果（スコア・解説）がスプレッドシートに自動保存**
   - `AnalysisCache` シートに最新の作文・添削が記録されるとともに、`EssayHistory` シートに添削履歴が1行ずつ蓄積
   - 少しずつ何回かに分けて改善していきたい学習者の推敲プロセスをすべて安全に記録
3. **Google Drive連携 & 過去の作文・添削の自動復元 📁**
   - 解析対象となった画像は自身の Google Drive に自動保存
   - **「📁 Driveから選択」ボタン**から過去の画像を選ぶと、画像解析結果だけでなく、**以前書いたあなたの中国語作文とAI添削結果も瞬時に自動復元**
   - Drive一覧上でも「⚡ 解析済み」や「✍️ 作文あり（〇〇点）」のバッジが表示され、学習の進捗が一目でわかります
4. **レベル別模範作文の表示**
   - 初級（HSK 1-2 相当）および中級（HSK 3-4 相当）の模範作文をピンイン・日本語訳・解説付きで生成
5. **音声読み上げ（Web Speech API）**
   - 各単語、例文、模範作文、添削後テキストをネイティブ中国語（普通話）で音声再生
6. **安全なアーキテクチャ**
   - Gemini APIキーはフロントエンドに埋め込まず、GASのスクリプトプロパティで安全に管理
   - スプレッドシートやGoogle DriveもGAS側で自動作成・安全管理
   - フロントエンド（HTML/CSS/Vue.js）とバックエンド（GAS）の完全分離

## 🚀 セットアップ手順

### ステップ 1: Google Apps Script (GAS) の準備

1. [Google Drive](https://drive.google.com/) を開き、左上の「+ 新規」>「その他」>「Google Apps Script」を選択します。
2. 本プロジェクトの `gas/Code.js` の内容をコピーし、GASのコードエディタに貼り付けます。
3. プロジェクト名をお好みの名前（例: `中国語写真作文API`）に変更して保存します。

### ステップ 2: Gemini API キーの登録 (スクリプト プロパティ)

1. GAS画面の左メニューにある **「プロジェクトの設定」 (⚙️ 歯車アイコン)** をクリックします。
2. 画面下部の **「スクリプト プロパティ」** セクションで **「スクリプト プロパティを追加」** をクリックします。
3. 以下のプロパティを追加して **「スクリプト プロパティを保存」** をクリックします:
   - **プロパティ名:** `GEMINI_API_KEY`
   - **値:** あなたの Gemini API キー (Google AI Studio で取得したもの)
   - *(任意)* **プロパティ名:** `DRIVE_FOLDER_ID`（画像を保存したい既存DriveフォルダのID。未設定時は「中国語写真作文_Images」フォルダが自動作成されます）

### ステップ 3: GAS の Web アプリとしてデプロイ

1. 画面右上の **「デプロイ」** > **「新しいデプロイ」** をクリックします。
2. 種類の選択（歯車アイコン）で **「ウェブアプリ」** を選択します。
3. 以下の設定を行います:
   - **説明:** `初期デプロイ`
   - **次のユーザーとして実行:** `自分` (Your account)
   - **アクセスできるユーザー:** `全員` (Anyone) ※必須
4. **「デプロイ」** をクリックし、アクセスを承認します。
5. 表示された **「ウェブアプリのURL」**（`https://script.google.com/macros/s/.../exec`）をコピーします。

---

### ステップ 4: Webアプリの起動とURL設定

#### 方法A：全端末で共通化する（おすすめ 🌟）
1. `js/config.js` をエディタで開き、`GAS_URL` にコピーしたURLを貼り付けて保存します：
   ```javascript
   const CONFIG = {
     GAS_URL: "https://script.google.com/macros/s/AKfycb.../exec"
   };
   ```
2. これにより、PCやスマホどの端末から開いても自動的にGASと接続され、端末ごとの手動入力が不要になります。

#### 方法B：画面上から手動入力する
1. `index.html` を任意のWebブラウザで開きます。
2. 画面右上の **「⚙️ (設定)」** アイコンをクリックし、ウェブアプリURLを貼り付けて **「設定を保存」** をクリックします。

> 💡 **デモモードについて**:
> GASのURLが未設定の場合でも、サンプル写真とモックデータにより画面の操作感や単語表示・添削UIをすぐにお試しいただけます。
